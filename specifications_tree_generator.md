# Context

The OpenRCT2 let the user place trees; it would be a neat addition to have a tree generator inside the rct_cycles_graphics.

The tree sprites were generated with blobs, spheres and noise textures. Propose a detailed specification for generating different types of trees, while making this compatible with the existing add-on.

Let the user:
- Decide the object size (full-tile, quarter-tile, etc)
- Recolourable materials for the trunk and leaves and non-recolourable materials, which can be later on customized by the user.
- The trunk size i.e. start, end, etc.
- The leaves size
- The trunk shape, i.e. adjust how straight it is
- How many branches are there

Propose a detailed specifications for this.
